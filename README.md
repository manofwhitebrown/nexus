# Nexus

A personal system for tasks, notes, links and projects. Everything stays in your browser (localStorage). No server, no account.

## Put it on GitHub Pages
1. Create a new GitHub repo (for example `nexus`) and upload everything in this folder.
2. Repo Settings > Pages > Source: "Deploy from a branch" > Branch: `main`, folder `/ (root)` > Save.
3. After a minute your app is live at `https://YOUR-USERNAME.github.io/nexus/`.

## Install on your phone
Open that URL in Chrome on Android, then menu > Install app (or Add to Home screen). On iPhone use Safari > Share > Add to Home Screen.

## Updating
Edit `index.html`, then bump `VERSION` in `sw.js` (for example `nexus-v2-2`) so installed copies refresh.

## Backup
Your data lives only in that browser. Use Settings > Export backup now and then.
